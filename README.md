# FITM Project Tracker — CoopConnect + Custom Projects

เว็บติดตามความคืบหน้าสำหรับทีม ใช้ HTML, CSS, JavaScript และ Supabase Database/Auth/Storage
เผยแพร่ด้วย GitHub Pages ได้ โดยเจ้าของ Repository เป็นผู้ Merge และ Deploy เอง

## ฟีเจอร์

- **CoopConnect เดิม:** นำเข้าข้อมูล 10 สัปดาห์ / 68 ข้อจาก `data.js` เข้า Supabase แล้ว (Project slug `coopconnect-original`)
- **หลายโครงการ:** เลือกโครงการจากเมนูด้านบนหรือสร้างโครงการใหม่ โดยกำหนดชื่อและ **จำนวนสัปดาห์ตั้งแต่ 1–104**
- **สร้างสัปดาห์ใหม่:** โครงการใหม่ได้สัปดาห์ว่างตามจำนวนที่กรอกตั้งแต่เริ่มต้น; แก้เป้าหมาย งานที่ทำร่วมกัน และผลส่งมอบ
- **จัดการข้อ:** เพิ่มข้อ แก้ชื่อ/เลขข้อ/บทบาท/รายละเอียด/รายการย่อย ย้ายไปสัปดาห์อื่น เปลี่ยนสถานะและบันทึกโน้ต
- **หลักฐานภาพ:** แนบ JPG/PNG/WebP หลายรูปต่อข้อ พร้อมคำอธิบาย อัปโหลดผ่าน Supabase Storage แบบ Private, ไม่เกิน 5 MB ต่อรูป และ UI จำกัดไม่เกิน 30 รูปต่อข้อ
- **Dashboard:** แสดงจำนวนสัปดาห์ งานทั้งหมด สถานะ และเปอร์เซ็นต์รายสัปดาห์/รวม พร้อมค้นหาและกรอง
- **การทำงานร่วมกัน:** คนทั่วไปเห็นชื่อโครงการ/สัปดาห์/ข้อ/โน้ตได้; เฉพาะสมาชิกตาราง `tracker_editors` เขียนข้อมูลได้ การแสดงภาพหลักฐานต้องเข้าสู่ระบบ (ถึงแม้ไม่ใช่ Editor ก็ดูภาพได้)
- **Realtime:** อัปเดตข้อมูลร่วมกันผ่าน Supabase Postgres Changes และรีเฟรชเมื่อกลับเข้าแท็บ

## วิธีใช้งาน

1. เปิด `index.html` จาก GitHub Pages (เมื่อเจ้าของ Merge/Deploy เอง)
2. เลือกโครงการ `CoopConnect` จะเห็น 10 สัปดาห์และ 68 ข้อเหมือนข้อมูลต้นฉบับ
3. ล็อกอินด้วยบัญชี Supabase ที่มีสิทธิ์ Editor เพื่อแก้ไขสถานะ/โน้ต หรือจัดการโครงการ
4. กด **สร้างโปรเจกต์ใหม่** → กรอกชื่อโครงการและจำนวนสัปดาห์ → บันทึก
5. เลือกสัปดาห์ กด **แก้ไขสัปดาห์** เพื่อกรอกเป้าหมาย/งานที่ทำร่วมกัน/ผลส่งมอบ
6. กด **เพิ่มข้อ / งาน** ใส่เลขอ้างอิง หัวข้อ บทบาท รายละเอียด และรายการย่อย (แต่ละบรรทัดเป็นหนึ่งรายการ)
7. เปิด **อ่านรายละเอียดทั้งหมด / โน้ต** ของการ์ด → เลือกรูปแนบ พร้อมคำอธิบาย → ระบบบันทึกใน Supabase
8. คนอื่นเปิดเว็บไซต์เดียวกันจะเห็นสถานะงานใหม่จากฐานข้อมูลกลาง (ต้องล็อกอินเพื่อเปิดหลักฐานภาพ)

## ข้อควรระวัง

- **ก่อน Merge** ตรวจ Diff ใน PR, เปิดไฟล์บน Branch ของตัวเอง และทดสอบร่วมกับบัญชี Supabase จริง
- การจัดเก็บรูปภาพเป็น **Private Bucket** และใช้ Signed URL อายุ 15 นาทีเพื่อแสดงภาพ
- ตัวเว็บไซต์เป็น Public และชื่อโครงการ/สัปดาห์/ข้อ/โน้ต **เปิดให้อ่านได้สาธารณะ** ไม่ควรใส่ข้อมูลส่วนบุคคล/ความลับในโน้ตหรือรายละเอียด
- Editor คนใดก็สามารถแก้ไขงานได้ทุกโครงการ ยังไม่มีสิทธิ์แยกตามโครงการ
- งานต้นฉบับที่นำเข้ามี `source_key` และ **ปุ่มลบถูกปิดไว้ใน UI** เพื่อป้องกันการลบข้ออ้างอิงต้นฉบับโดยไม่ตั้งใจ
- ห้ามใส่ Secret Key, service_role หรือรหัสผ่านฐานข้อมูลในไฟล์เว็บ แม้ Repository จะเป็น Private
- URL, Publishable Key ที่ฝังใน Frontend ใช้ร่วมกับ Supabase RLS ตามปกติ
- หากต้องตั้งระบบใหม่ใน Supabase Project อื่น ให้รัน `supabase/SHARED_TRACKER_V2.sql` และนำเข้าข้อมูล `data.js` ด้วยกระบวนการแยก (ไฟล์ SQL Schema ไม่ได้สร้าง 68 ข้อให้เอง)
